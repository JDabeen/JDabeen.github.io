# 숙제공지 자동화 | 실제 학원에서 사용 중인 프로그램

**반별 숙제공지 작성 약 30분 → 3분 이내** · 동료 강사들이 실제 업무에서 사용

교재·수업 일차마다 숙제 페이지, 녹음 과제, 음원 링크를 찾아 조합하던 작업을 규칙 기반으로 자동화했습니다. *(소요시간은 직접 수행한 업무 기준의 체감치입니다.)*

**[프로그램 직접 체험하기](https://jdabeen.github.io/homework-automation-demo/)**

## 핵심 구현

- **54권의 교재별 규칙:** Basic 12권·Intermediate 12권·Foundation 30권의 숙제 범위와 Review Day 등 예외 처리
- **음원 오류 방지:** 조건에 맞는 파일이 **정확히 하나**인지 검사하고, 누락·중복 시 오류 표시
- **설치 없는 실행:** Python·Google Colab 시제품을 **HTML·CSS·JavaScript 단일 파일**로 전환

## 실제 사용까지

처음에는 Colab에서 공지가 생성되는 것만으로 충분하다고 생각했습니다. 하지만 동료 강사들이 새로운 도구 사용을 부담스러워하는 모습을 보며, **기능이 작동하는 것과 현장에서 쓰이는 것은 다르다**는 점을 확인했습니다.

별도 설치 없이 열 수 있게 바꾸고, 기존의 **반·교재·일차 선택 → 공지 생성 → 복사** 흐름을 유지했습니다. 동료들이 요청한 입력 방식과 공지 형식도 수정했고, 실제 업무에서 사용하게 됐습니다.

## 검증 · 기술

- **검증:** Colab과 HTML의 공지 출력 비교, 음원 누락·중복 및 특수 Unit·Review Day 점검
- **담당:** 업무 분석, 규칙 정리, 요구사항 반영, 출력 검수, 현장 적용
- **개발:** Python·Colab → HTML·CSS·JavaScript. GPT·Claude는 코드 작성·수정과 테스트 구성에 보조적으로 활용
- **실행:** AI API 없이 JavaScript 규칙으로 생성
