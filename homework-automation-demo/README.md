# 숙제공지 자동화

**실제 학원에서 사용 중인 업무자동화 프로그램**

반별 약 **30분** 걸리던 숙제공지 작성을 **3분 이내**로 줄였습니다. 교재별 계획표와 음원 링크를 매번 찾아 조합하던 작업을 자동화했고, 동료 강사들도 실제 업무에서 사용하고 있습니다.

**[프로그램 직접 체험하기](https://jdabeen.github.io/homework-automation-demo/)** · [개발 과정 상세 보기](./TECHNICAL_NOTES.md)

## 해결한 문제

| 현장에서 반복되던 일 | 구현한 해결 방법 |
| --- | --- |
| 교재·Unit·일차별 숙제 범위 확인 | **54권의 교재 규칙**을 정리해 선택값에 따라 자동 입력 |
| 본문·Q&A 등 음원 링크 수작업 검색 | **음원 매칭 자동화** 및 누락·중복 오류 검사 |
| 선생님마다 공지 작성·복사 | **공지 자동 생성**과 전체 복사 기능 |
| 새 프로그램을 배우고 설치해야 하는 부담 | **Colab → 단일 HTML 웹앱**으로 전환 |

## 프로그램을 만드는 것보다 어려웠던 일

첫 시제품은 Python·Google Colab에서 작동했습니다. 하지만 동료들이 새 도구를 사용하는 데 부담을 느꼈습니다.

그래서 기존 업무 순서를 거의 바꾸지 않았습니다. **반·교재·일차 선택 → 숙제 확인 → 공지 생성 → 복사.** 입력 방식과 공지 형식을 현장 피드백에 맞춰 수정했고, 실제 수업 업무에 사용하는 도구로 발전시켰습니다.

## 구현 · 검증

**Python · Google Colab → HTML · CSS · JavaScript**

교재별 예외 규칙(Review Day 등)과 음원 누락·중복을 검사하고, Colab과 HTML이 생성한 공지 결과를 비교했습니다.

GPT·Claude는 코드 작성·수정 및 테스트 구성에 보조적으로 사용했습니다. 실제 공지는 **AI API 호출 없이 규칙 기반**으로 생성됩니다.
