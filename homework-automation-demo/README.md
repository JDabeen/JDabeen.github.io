# 숙제공지 생성기 | 현장에서 실제 사용하는 업무자동화 도구

**반마다 약 30분 걸리던 숙제공지 작성 시간을 3분 이내로 줄였습니다.**  
처음에는 새 도구를 꺼리던 동료들도 지금은 실제 수업 업무에 사용하고 있습니다.

**[프로그램 직접 체험하기](https://jdabeen.github.io/homework-automation-demo/)** · [공개 데모 코드](./index.html)

> 이 페이지는 실제 학원에서 사용하는 프로그램의 개발 기록입니다. 체험판은 **원본 UI와 주요 작업 흐름을 유지**하면서 교재·숙제·음원 데이터를 가상 자료로 바꾼 공개용 버전입니다.

## 출발점: 왜 매일 같은 정보를 다시 찾아야 할까?

영어강사로 일하며 매일 숙제공지를 작성했습니다. 공지 문장 자체는 어렵지 않았지만, 교재·Unit·수업 일차가 바뀔 때마다 계획표에서 페이지를 찾고, 녹음 과제를 확인하고, 맞는 음원 번호와 링크를 다시 연결해야 했습니다.

문제는 **글을 쓰는 속도**가 아니라 **흩어진 정보를 매번 찾아 조합하는 과정**이었습니다. 일정한 기준으로 답을 구할 수 있는 업무라면 사람이 반복할 이유가 없다고 판단했습니다.

## 구현에서 중요했던 세 가지 결정

### 1. 공지 문장이 아니라 ‘공지의 기준’을 자동화

먼저 교재·Unit·학습 일차를 기준으로 숙제 범위, 녹음 항목, 음원 정보를 정리했습니다. 운영본에는 **Basic 12권, Intermediate 12권, Foundation 30권**의 규칙을 반영했습니다.

여기서 어려웠던 건 단순한 문구 생성이 아니라 **예외 처리**였습니다. Review Day, 특정 Unit의 트랙 번호 변경, Foundation의 Phonics·Phonics Story·Story·Chant 구분처럼 조건에 따라 달라지는 내용을 따로 정의했습니다.

음원 링크도 단순 검색으로 연결하지 않고 **일치 후보가 정확히 하나인지** 확인하도록 설계했습니다. 잘못된 음원을 아무 오류 없이 보내는 것보다, 찾지 못했음을 알려 강사가 확인하도록 하는 편이 현장에서 안전하다고 판단했기 때문입니다.

### 2. Colab에서 작동하는 도구를, 동료가 바로 쓰는 도구로

처음에는 **Python·Google Colab**에서 공지 생성 로직을 만들었습니다. 하지만 동료들이 매번 개발 환경을 열거나 설정해야 한다면 실제 사용으로 이어지기 어렵다고 판단했습니다.

그래서 **HTML·JavaScript 단일 파일**로 전환했습니다. 별도 설치·로그인 없이 브라우저로 열 수 있고, 생성 규칙과 데이터가 파일 안에 있어 **공지 작성 자체는 인터넷 없이** 가능합니다. 음원 링크를 열 때만 인터넷이 필요합니다.

### 3. 기능 완성보다 실제 사용 흐름을 우선

새 도구에 부담을 느끼는 동료들의 요구를 듣고 입력 과정과 공지 형식을 계속 수정했습니다.

**반·교재·일차 선택 → 숙제 범위 자동 입력 → 공지 생성 → 전체 복사.** 기존 업무 순서를 크게 바꾸지 않으면서 수작업을 줄이는 데 집중했습니다. 이후 커리큘럼 시작·종료일, 다음 레벨 예상일, 전체 숙제계획표 확인 기능도 반영했습니다.

그 결과 동료들이 실제 업무에 도구를 사용하게 됐습니다. 제가 해결하고 싶었던 것은 프로그램 제작 자체가 아니라 **사람들이 매일 반복하던 일을 줄이는 것**이었습니다.

## 결과와 검증

- **작업 시간:** 반별 약 **30분 → 3분 이내**. 직접 수행한 업무의 전후 소요시간 기준으로, 별도의 통제 실험 수치는 아닙니다.
- **현장 적용:** 동료 강사의 의견을 받아 개선했고, 현재 실제 숙제공지 작성에 사용하고 있습니다.
- **출력 검증:** 기존 Colab과 최종 HTML의 일반·Review 공지 출력을 비교했습니다.
- **규칙 검증:** Basic·Intermediate 각 12권 × 4개 Unit의 본문·Q&A·어휘 음원 매칭, Foundation 30권 × 15일차의 공지 규칙과 음원 구분, 특수 Unit 예외를 검사했습니다.

검증의 목표는 ‘버튼을 누르면 글이 나온다’가 아니라 **해당 수업에 맞는 공지가 빠짐없이 나오는가**였습니다.

## 내가 맡은 일과 기술 범위

**직접 담당:** 반복 업무 분석, 필요한 규칙 정리, 기능 우선순위와 입력·출력 방식 결정, 동료 피드백 수집, 생성 결과 검수 및 현장 적용.

**기술:** Python·Google Colab(초기 시제품) → HTML·CSS·JavaScript(최종 운영본).

**AI 활용:** GPT·Claude를 코드 작성·수정과 테스트 구성에 보조적으로 활용했습니다. **사용자가 숙제를 생성할 때는 AI 모델을 호출하지 않습니다.** 미리 정의한 규칙을 JavaScript로 처리하는 프로그램입니다.

실제 학원의 교재 데이터·음원 파일 ID·Google Drive 링크는 공개하지 않았습니다. 데모에는 가상 자료와 예시 링크만 사용하므로 **원본 운영본과 출력 내용까지 동일하지는 않습니다.**
