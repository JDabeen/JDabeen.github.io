# 숙제공지 생성기 | 현장 업무자동화

영어학원에서 매일 반복하던 숙제 공지를 규칙 기반으로 생성하도록 만든 프로그램입니다. **실제 운영 중인 원본 프로그램은 비공개**이며, 이 저장소 폴더에서는 핵심 기능을 재현한 가상 데이터 데모만 공개합니다.

**[프로그램 직접 체험하기](https://jdabeen.github.io/homework-automation-demo/)**

## 결과

| 항목 | 내용 |
| --- | --- |
| 업무시간 | 반별 약 **30분 → 3분 이내** (직접 수행한 업무 기준) |
| 도입 | 동료 강사의 피드백을 반영해 개선, 실제 업무에 활용 |
| 담당 | 문제 정의 · 데이터 정리 · 구현 검증 · 사용자 요구 반영 |
| 기술 | HTML · CSS · JavaScript / 초기 Python·Google Colab |

## 문제

수업마다 교사가 교재·단원·일차를 확인하고 숙제 범위와 음원 번호를 찾아 직접 공지로 옮겨 적었습니다. 예외는 있었지만 반복되는 규칙을 정리하면 자동화할 수 있다고 판단했습니다.

## 개발 과정

1. **업무 분해** — 과정별 숙제 항목과 수업 일차, 음원 번호, 예외 조건을 정리했습니다.
2. **시제품 제작** — Google Colab에서 입력값에 따른 공지 생성 규칙을 검증했습니다.
3. **도입 장벽 개선** — 동료들이 별도 설치 없이 사용할 수 있도록 단일 HTML 웹앱으로 전환했습니다.
4. **현장 개선** — 실제 사용자 요청에 따라 입력 항목, 출력 문구, 커리큘럼 표시 등을 수정했습니다.
5. **출력 검증** — 운영 버전의 음원 매칭과 예외 규칙, 기존 Colab 출력 결과와의 일치 여부를 확인했습니다.

개발 목표는 기능을 많이 넣는 것이 아니라 **동료들이 실제로 사용하는 작업 흐름을 만드는 것**이었습니다.

## 공개 범위

이 데모는 가상 반 2개·샘플 교재 2개만 사용하며 입력 → 규칙 적용 → 공지 생성 → 복사를 보여주는 독립 구현입니다. 원본의 Foundation·Basic·Intermediate 과정, 실제 교재 DB, 비공개 음원 URL 등은 공개하지 않습니다. 따라서 **원본의 모든 기능을 제공하는 복제본은 아닙니다**.

## AI를 사용한 범위

GPT와 Claude는 개발 과정에서 코드 작성 보조 도구로 사용했습니다. 사용자 요구 파악, 업무 규칙 정의, 적용 검증은 직접 담당했습니다. 실제 실행 시에는 AI API를 호출하지 않고 JavaScript 규칙으로 공지를 만듭니다.
